# react-dashboard

[![CI](https://github.com/marcus-beauregard/react-dashboard/actions/workflows/ci.yml/badge.svg)](https://github.com/marcus-beauregard/react-dashboard/actions/workflows/ci.yml) [![License: GPL-2.0-or-later](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](LICENSE)

A responsive dashboard built with React 17 and Vite. Renders asset tiles,
a geolocation-based local temperature, and a dark/light theme toggle.

## Development

- `npm install` — install dependencies
- `npm run dev` — start the Vite dev server
- `npm run build` — produce a production build in `dist/`
- `npm run preview` — preview the production build
